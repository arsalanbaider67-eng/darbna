سياسة الخصوصية — 18 أكتوبر 2026

دربنا تطبيق ملاحة للعراق دون حساب أو إعلانات أو تتبع إعلاني. عدم طلب الاسم لا يعني أن بيانات الموقع مجهولة بالكامل.

الموقع والخدمات الخارجية

يُستخدم الموقع أثناء فتح التطبيق. تُرسل البداية والوجهة إلى خدمة Valhalla لحساب الطريق، ونص البحث والمنطقة التقريبية إلى Nominatim أو Esri أو خدمة البحث المهيأة. تُستخدم OpenFreeMap وOpenStreetMap وOverpass لعرض الخرائط والأماكن، وEsri للصور الفضائية عند توفرها. تستقبل هذه الخدمات عنوان الإنترنت وبيانات الطلب اللازمة لتشغيلها. لا نبيع بياناتك.

تعمل خدمتا حساب الطرق والبحث عن الأماكن الخاصتان بدربنا على خادم تستضيفه Contabo داخل الاتحاد الأوروبي. تسجيل طلبات الوصول إلى هاتين الخدمتين متوقف، وتُحذف بيانات الطلب من سجلات أخطاء وسيط HTTPS. تستمر خدمات الخرائط والصور الفضائية وملاحظات الخريطة العامة وميزات المجتمع في الاتصال بمقدمي الخدمات المذكورين أعلاه.

البلاغات والمشاركة الاختيارية

تُخزّن البلاغات والتصويتات والنقاط على Supabase مع الموقع والوقت ورمز عشوائي خاص بتثبيت التطبيق، يُخزّن مشفّرًا كتجزئة. لمنع الإساءة يُخزّن أيضًا تجزئة عنوان الإنترنت. البلاغات عامة دون نشر رمز الجهاز.

مساعدة الزحام متوقفة افتراضيًا. عند تشغيلها أثناء الملاحة الحقيقية، نرسل عينات الموقع والسرعة والاتجاه وأحداث التوقف مع رمز عشوائي للرحلة وتجزئة عنوان الإنترنت. يحجب التطبيق أول 300 متر، ويؤخر إرسال آخر 300 متر حتى تتقدم الرحلة. لا تُرسل هذه العينات في الجولة أو القيادة التجريبية. إيقاف الخيار يلغي العينات المنتظرة.

مشاركة الرحلة ترسل موقعك ووجهتك ووقت الوصول إلى Supabase أثناء فتح التطبيق. يستطيع كل من يملك الرابط الاطلاع عليها أو إعادة مشاركته. توقف المشاركة عند إنهائها؛ ينتهي وصول الرابط بعد 30 دقيقة دون تحديث.

الاحتفاظ والحذف

حدود التنظيف المبرمجة: عينات السرعة أقدم من ساعتين، التوقفات أقدم من 90 يومًا، المشاركة دون تحديث ليوم، والبلاغات المنتهية لأكثر من أسبوع وفق حالة البلاغ. التنظيف الحالي يعمل عند وصول طلبات جديدة، لذلك قد تبقى السجلات أطول إذا توقف الاستخدام؛ لا نعد بموعد حذف تلقائي مضمون. تُعرض بيانات الزحام المجمعة بدلًا من العينات الفردية.

الإعدادات ← مسح بياناتي يحذف البلاغات والتصويتات والنقاط والمشاركات المرتبطة برمز هذا التثبيت بعد تأكيد الخادم، ثم يمسح الأماكن المحفوظة والسجل والرحلة ومكان الوقوف محليًا. لا يمحو عينات الرحلات غير المرتبطة برمز التثبيت، أو سجلات مزودي الخدمة، أو نسخ الروابط التي حفظها الآخرون. تبقى الإعدادات والخرائط المحملة؛ امسح الخرائط من خيارها المنفصل.

ملاحظات الخريطة

النص والموقع المرسلان عبر نموذج مشكلة الخريطة يُنشران كملاحظة عامة لدى OpenStreetMap. لا تضع معلومات شخصية فيها؛ مسح بيانات دربنا لا يحذف هذه الملاحظات الخارجية.

التواصل

الدعم والإبلاغ عن الإساءة. بلاغات GitHub عامة وتتطلب حساب GitHub؛ لا تنشر موقعك الخاص أو أرقامك فيها.

مراجعة البلاغات ومنع الإساءة

تُراجع البلاغات المشتبه بها قبل احتساب المخالفة. تؤدي خمسة بلاغات منفصلة ثبت أنها مزيفة أو مسيئة إلى حظر إرسال البلاغات والتأكيدات. نحتفظ بقرارات المراجعة وأسبابها ورمز التثبيت المجزأ اللازم لإنفاذ الحظر، حتى بعد انتهاء البلاغ أو مسح بيانات التطبيق العادية. هذه السجلات ليست عامة. يمكن طلب مراجعة القرار عبر darbnaiq@gmail.com.

Privacy policy — 18 October 2026

Darbna provides navigation in Iraq without accounts, ads or advertising tracking. Not asking your name does not make location data fully anonymous.

Location and providers

Location is used while the app is open. Route endpoints go to the configured Valhalla service. Search text and an approximate area go to Nominatim, Esri or the configured search provider. Maps and places use OpenFreeMap, OpenStreetMap and Overpass; optional satellite imagery uses Esri. Providers receive your IP address and request data needed to operate their services. We do not sell data.

Darbna’s routing and place-search services run on a Contabo server in the European Union. Access logging for these two services is disabled, and request objects are removed from HTTPS proxy error logs. Map tiles, satellite imagery, public map notes and community features still contact the providers described above.

Reports and optional sharing

Reports, votes and points are stored on Supabase with location, time and a random installation code, stored as a salted hash. An IP-address hash is used for abuse prevention. Report details are public; the installation code is not published.

Traffic contribution is off by default. If enabled during real navigation, location, speed, heading and stop events are sent with a random trip code and an IP-address hash. The app withholds the first 300 m and buffers the latest 300 m until you travel farther. Tour and demo drives do not contribute. Switching contribution off drops pending samples.

Optional trip sharing sends your position, destination and ETA to Supabase while the app is open. Anyone with the link can view or forward it. End sharing to stop updates. Access expires after 30 minutes without an update.

Retention and deletion

Configured cleanup thresholds are two hours for speed samples, 90 days for stop events, one day without updates for shared trips, and seven days after report expiry depending on report status. Cleanup currently runs on new submissions, so records can remain longer when usage stops; these are not guaranteed automatic deletion deadlines. Public traffic views show aggregates rather than individual samples.

Settings → Delete my data waits for server confirmation before clearing reports, votes, points and shared trips associated with this installation, then clears local saved places, history, current trip and parked position. It does not erase trip samples unlinked to the installation code, provider logs, or copies of shared links. Settings and downloaded maps remain; use the separate map removal control.

Public map notes

The map-problem form publishes your text and location as an OpenStreetMap note. Do not include personal information. Deleting Darbna data does not remove these external notes.

Contact

Support and abuse reports. GitHub issues are public and require a GitHub account. Do not post private locations or contact details.

Report review and abuse prevention

Suspected reports require an owner review before counting as an offence. Five distinct reports confirmed as fake or abusive lead to a reporting and confirmation ban. Review decisions, reasons and the hashed installation identifier needed to enforce moderation are retained after report expiry and normal app-data deletion. They are private. Request a correction or appeal at darbnaiq@gmail.com.
